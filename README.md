# Course Enrollment System

# Project Overview

A complete full stack application for a Course Enrollment System. The system allows an Admin to manage users, courses, teacher assignments, and enrollments; Teachers to manage their assigned courses and view enrolled students; and Students to discover published courses and enroll in them.

# Technology stack used

MERN Stack (MongoDB, Express.js, React.js, Node.js)

# Frontend setup instructions

Frontend is build on React.js

In the project directory, to download used package you can firt run:

### `npm install `

To run backend

### `npm start `

# Frontend github url

https://github.com/MansiRK/course_enrollment_system_fe.git

# Backend setup instructions

Backend is build on Express.js and Node.js. MongoDB is used as database to store data.

In the project directory, to download used package you can firt run:

### `npm install `

To run backend

### `npm start `
